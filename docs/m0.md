# M0: the service door

Before any of the Hotel Meridian is built, the idea file's plan asks for
two weeks on one room, one guard and one door, to prove that talking to a
character can feel like talking. This document says what is built, what
has to be measured on real hardware, and where to write the numbers down.

## What is built

- **The room.** The Meridian's service corridor (`game/world/service_door_room.gd`),
  built from the Downtown City MegaKit, with the service door at the north
  end. Marcus, a Halberd Security guard, stands beside it.
- **Hearing.** `LGVoice` (`addons/linuxgroove/voice/`) opens Lemonade's
  realtime transcription socket, streams the microphone to it while you
  hold the talk button, shows partial words as they arrive, and commits the
  turn when you let go. If the socket is not there it falls back to one
  transcription request per turn. The hearing model is a setting
  (Whisper-Tiny, Base or Small).
- **Earshot.** `Earshot` turns distance and voice (whisper, normal, shout)
  into clarity: every word within the first range, words dropping out up to
  the second, nothing beyond it. What Marcus heard, and how well, goes into
  his prompt.
- **Brains.** `Guard` keeps Marcus's sheet (`CharacterSheet.marcus()`),
  prompt (`GuardPrompt`) and history, and asks the model through
  `BrainQueue` and `LGBrain` with the reply schema (`ReplySchema`) as a
  `json_schema` response format. `GuardRules` applies the rules to each
  reply: suspicion moves at most two steps a turn, letting you through
  needs trust and at least two turns, radioing security needs suspicion 4,
  and suspicion 5 ends it. A reply that is slow (`BrainQueue.TIMEOUT`,
  9 seconds) or missing becomes a scripted line, so the door always
  answers. The kitchen code is never in the prompt, so he cannot be talked
  into saying it.
- **Speaking.** Each reply goes to Kokoro through Lemonade one sentence at
  a time; the first sentence plays as soon as it is back, placed at
  Marcus's mouth, and the sound's envelope moves his jaw (`Face`).
- **The schema probe.** At start, `BrainQueue.probe_schema()` sends a
  one-word schema whose only allowed word is "pineapple". A server that
  enforces `response_format` answers with it; the HUD then says
  **Schema: enforced**. Anything else says **not enforced**, and every
  turn's `strict` column says whether the reply still happened to follow
  the schema.
- **The readout.** The HUD's bottom line shows, per turn: how long the
  hearing took after you let go (and when the first word arrived), how long
  the model thought (and how many prompt tokens the cache reused), whether
  the reply was strict, and how long the first sound took.
- **The record.** When the door ends, every turn's timings go to
  `user://m0/door-<timestamp>.json` (on Linux,
  `~/.local/share/silver-tongue/m0/`, or `~/snap/silver-tongue/common/.local/share/silver-tongue/m0/`
  from the snap), and the result card sums them up.
- **The bench.** `tools/m0_bench.tscn` runs the probe and a set of lines
  through the whole stack against a real Lemonade, with no one at the
  microphone, and prints a table and a summary.

## What has to be measured

The plan's four points, and who does them. Everything below needs real
hardware: the container these tools were written in has no GPU and cannot
reach Hugging Face, so the tests run against a fake Lemonade
(`tools/fake_lemonade.py`) and the numbers here are blank until Ken fills
them in.

### 1. Hearing on the Legion Go S

Run the door with a microphone and hold V while you talk. The readout's
"heard" number is the time from letting go to the whole line; "first word"
is when the first partial arrived. Say ten lines at each hearing model and
count the ones he got wrong.

| Model | First word (s) | Whole line after letting go (s) | Lines misheard of 10 |
|---|---|---|---|
| Whisper-Tiny | | | |
| Whisper-Base | | | |
| Whisper-Small | | | |

The plan says to try Moonshine second if whisper is too slow. That is not
built: it needs a second sidecar (sherpa-onnx), and only matters if these
numbers are bad.

### 2. Brains

The bench does this without you talking. On the handheld and on a desktop
GPU, with each model:

```sh
godot --path . tools/m0_bench.tscn -- --model=LFM2.5-1.2B-Instruct-GGUF --runs=2 --out=/tmp/m0-1.2b.json
godot --path . tools/m0_bench.tscn -- --model=Qwen3-4B-Instruct-2507-GGUF --runs=2 --out=/tmp/m0-4b.json
```

Each run's first line is from scratch (the whole prompt read); the rest
find the system prompt in the cache. The summary prints both. The schema
line says whether Lemonade passed `response_format` through.

| | 1.2B handheld | 4B handheld | 1.2B desktop GPU | 4B desktop GPU |
|---|---|---|---|---|
| Schema enforced | | | | |
| Thought, from scratch (s) | | | | |
| Thought, cached, mean (s) | | | | |
| Prompt tokens, cached of total | | | | |
| Strict replies of total | | | | |

The budget is about two seconds from the end of your sentence to his
first sound on the handheld, under one on a desktop. "Thought" is the
middle of that; add the hearing and speaking numbers.

**Answering what he shouldn't.** Play the door and try, over ten turns, to

### 4. Three people

Three people who have never seen the game, one at a time, no script: can
they talk their way past Marcus, and do they say afterwards that he
listened? Turn on Play test recording in the settings (or run with
`-- --playtest`), so each one's run, notes and survey land in
`user://playtest/`, and keep the `user://m0/` records.

| Person | Through, caught or gave up | Turns | Said he listened |
|---|---|---|---|
| 1 | | | |
| 2 | | | |
| 3 | | | |

If they do not say he listened, the design changes before any content is
written. The most likely changes are in the prompt and the sheet
(`game/brain/`), the earshot ranges (`Earshot.RANGES`) and the rules'
limits (`GuardRules`).

## Pointing the game at Lemonade

The snap bundles Lemonade and starts it itself. From source, the game looks
for an installed `lemond` and otherwise waits for one at the external
address. For one run:

```sh
godot --path . -- --door --set=ai/mode=external --set=ai/external_url=http://localhost:8000/api/v1
```

The settings page also has the hearing model, whether he speaks out loud,
the readout, and whether to ask him to mind his language.

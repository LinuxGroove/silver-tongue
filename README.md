# Silver Tongue

*Talk your way in. Everyone can hear you.*

A co-op con game where the characters listen, for Linux PCs and handhelds,
made with Godot 4. Part of [LinuxGroove Games](https://linuxgroove.com);
the concept is idea 23 in
[game-ideas](https://github.com/LinuxGroove/game-ideas/blob/main/ideas/23-silver-tongue.md).

Made by Drew, Kaden and Ken VanDine, the LinuxGroove team. MIT licence
